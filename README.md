# WordPress + Tainacan

Sistema para acervos históricos e museus. Projeto criado para a realização de uma bolsa no IFRS em parceria com o Circolo Trentino di Bento Gonçalves no ano de 2026.

## Objetivo

O uso do WordPress + Tainacan tem como objetivo criar um sistema que consiste em um site institucional com um painel de administrador para controlar o conteúdo do site.

## Atividades realizadas

As atividades podem ser divididas em 3 itens:

- Mudança e adequação do layout com o estilo (cores e imagens) do Circolo Trentino.
- Criação dos registros e páginas que serão adicionados no site.
- Envio das informações dos registros para a API do Sistema Nacional de Museus. Nesse item, é realizado um mapeamento dos dados para o envio.
